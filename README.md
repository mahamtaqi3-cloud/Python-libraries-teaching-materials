# Python Libraries — Practice Notebooks

A collection of hands-on Colab notebooks covering essential Python libraries for **data analysis, visualization, and web scraping**. Built as companion practice material to the [6-Week Python Course](../) — useful on its own as a quick-reference/practice repo for these libraries.

## Libraries covered

| Library | What it's for |
|---|---|
| [NumPy](#numpy) | Numerical computing — arrays, vectorized math, linear algebra basics |
| [Pandas](#pandas) | Loading, cleaning, and analyzing tabular data (CSVs, DataFrames) |
| [Matplotlib / Seaborn](#matplotlib--seaborn) | Turning data into charts and visualizations |
| [BeautifulSoup](#beautifulsoup) | Parsing HTML and scraping data from web pages |

## Getting started

1. Open any notebook directly on GitHub, or click **"Open in Colab"** at the top of the notebook.
2. Make a copy to your own Google Drive to save your changes: **File → Save a copy in Drive**.
3. Run the cells top to bottom — each notebook is self-contained with explanations and runnable examples.

No installation needed — everything runs in Google Colab, which comes with these libraries pre-installed.

## What's in each folder

### NumPy
Creating arrays, indexing/slicing, reshaping, broadcasting, and vectorized operations — the foundation for Pandas and most numerical work in Python.

### Pandas
Working with `Series` and `DataFrame` objects, reading data from CSV files, filtering and selecting data, handling missing values, and basic data cleaning/transformation.

### Matplotlib / Seaborn
Line plots, bar charts, histograms, and scatter plots with Matplotlib; cleaner statistical visualizations and styling with Seaborn.

### BeautifulSoup
Parsing HTML documents, navigating the DOM tree, and extracting text/links/tables from web pages for basic web scraping.
